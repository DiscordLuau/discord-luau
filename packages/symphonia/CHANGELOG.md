## [Unreleased]

### Added

- `symphonia.decoder.fromBuffer(bytes, options?)` and `symphonia.decoder.fromFile(path, options?)` open an audio file, held in memory as a buffer or string or streamed from the disk, through libsymphonia, a Rust wrapper around Symphonia 0.6.1 loaded over FFI. They raise `could not open audio: <message>` for anything that cannot be opened, including a path that contains a NUL byte
- `decoder:read()` returns up to 100 ms of 48 kHz interleaved stereo 16-bit little-endian PCM at a time, resampled with an exact length, and nil at the end. It covers AAC-LC (mono or stereo), MP1, MP2, MP3, FLAC, Vorbis, PCM, ADPCM (mono or stereo) and ALAC in WAV, AIFF, CAF, Ogg, MKV, WebM, MP4 and M4A; PCM, FLAC, Vorbis and ALAC in any channel layout are mixed to stereo. AAC with more than two channels fails to open, and implicitly signalled HE-AAC plays only its AAC-LC core. Decode errors raise `could not decode audio: <message>`; an undecodable packet is skipped, counted in `skippedPackets` and warned once per decoder
- `decoder:readPacket()` passes Opus in Ogg, WebM, MKV and MP4 through as raw packets, without decoding it; a file with more than one Opus stream fails to open
- A decoder's `codec`, `container`, `sampleRate`, `channels`, `durationSeconds`, `isOpus`, `ended`, `endedEarly`, `destroyed` and `skippedPackets` describe the file and the read so far, and `decoder:destroy()` closes its native session and file
- A file cut short plays the audio it holds and ends cleanly; when decoding ends short of the length the file states, `endedEarly` is set and the decoder warns `the audio ended early, short of the length the file states; it may be truncated or damaged` once; skipped damaged packets count as missing audio. A file that states no length, such as a WAV streamed with unknown sizes, and Opus, which is passed through, are never flagged. Truncated Ogg, AIFF, CAF, MKV and MP4 files fail at open
- `symphonia.decode(bytes, options?)` decodes a whole non-Opus file to one PCM buffer, raising past `options.maxSeconds` (3600 by default)
- `symphonia.load()` loads the native library, which otherwise loads on first use rather than on require. Concurrent callers share one load, and a failed load is retried on the next call
- Hostile input is bounded: panics become errors, and sample rates outside 1000 to 384000 Hz, more than 32 channels and absurd packet sizes are refused at open
- The libsymphonia binaries are reproducible: `build-binaries.sh` rebuilds all six byte for byte, so the committed files and their checksums come from the build workflow's artifact
- `decoder:setVolume(volume)` and `decoder.volume` set the volume of the decoded PCM, a number from 0 to 4 (1 by default); anything else raises `volume must be a number from 0 to 4`. `read` and `symphonia.decode` turn the library's floats into 16-bit PCM in Luau, through the decoder's own `Limiter`: a volume change ramps over 20 ms and is heard 5 ms into the next read, and the limiter (5 ms look-ahead, linked stereo, a 50 ms release) stops audio that would pass full scale, such as a float WAV peaking at +6 dBFS, from clipping. Audio that never passes full scale decodes bit for bit as before, and frame counts are unchanged. Opus is passed through, so volume has no effect on it: the value is kept and the first call warns `volume has no effect on Opus passed through as stored`
- `symphonia.limiter.new()` creates that `Limiter` on its own, for floats from `readFloat`: `setVolume(volume)`, `process(floats, frames)`, which returns 16-bit PCM shorter by what the 240-frame look-ahead holds, and `flush()`, which returns the held frames at the end. `symphonia.limiter.checkVolume(volume)` owns the volume range and its message, and `symphonia.decoder.checkVolume` checks that a volume is a number before using it
- libsymphonia ABI 2 decodes to 48 kHz stereo 32-bit floats and leaves volume, limiting and the conversion to 16-bit to Luau; `decoder:readFloat()` returns those floats untouched. It also takes a file pushed in chunks as a stream session, decoded on a worker thread: `Sys` binds `symphonia_open_stream`, `symphonia_push`, `symphonia_finish` and `symphonia_worker_count`, info field 7 (`state`) and describe field 2 (the failure text). The binaries are rebuilt
- `symphonia.decoder.fromStream(options?)` opens a decoder for a file that arrives in pieces: `decoder:push(chunk)` queues bytes and returns false, with nothing queued, when the input is full; `decoder:finish()` ends the input; `decoder:refresh()` reads the session's `state` and fills the shape fields on the first open. A push the session cannot take raises `could not push audio: <reason>`. Reads on a stream never block: they return nil with `dry` set while nothing is ready and with `ended` set only at the true end, and `read` keeps its limiter running through dry reads. New fields: `opened`, `dry`, `state`, `failed`, `failure` and `failedBeforeOpen`
